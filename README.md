# Simulacro de auditoría de sistemas

Examen de práctica de 50 preguntas sobre protección de datos personales, NTP-ISO/IEC 27001:2022, gobierno digital y delitos informáticos. Las alternativas se mezclan en cada intento y el tiempo por pregunta se configura antes de empezar.

## Uso local

```bash
npm install
npm run dev
```

## Publicación

Vercel detecta Vite. El comando de build es `npm run build` y el resultado queda en `dist`.
